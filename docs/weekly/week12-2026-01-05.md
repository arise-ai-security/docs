## Key Accomplishments This Week

### Arise vs SEC-bench: Experiment Report

#### Goal
Create baseline metrics comparable to SEC-bench by varying only our system's internal structure.

#### Methodology

| Fixed Variables | Changed Variables                                     |
|-----------------|-------------------------------------------------------|
| 3-stage behavior (Builder, Exploiter, Fixer) | System structure (Naive Tree, Full Featured Tree)     |
| Input data (SEC-bench CVE instances) | Coding agents (Claude Code/Sonnet, OpenHands/GPT-4o/5) |
| Success criteria (`secb` return codes, `secb` implementation) |                                                       |

- Adopted codes and Dockerfiles directly from Sec Bench to fix variables.

#### Result Summary

Both approach (Naive tree, Full featured tree) showed improvements across all metrics compared to Sec Bench.

---

### Experiment 1: Naive Tree ([Full Report](../projects/arise-sec-lion/experiments/exp1-naive-tree.md))

**Architecture**
- Tree structure with Thinkers and Workers
- Hyperparameters: `max_depth`, `max_children`, `max_nodes`
- Context passing: parent→child (depth, task, decision), worker→sibling (task, result), global

**Results (n=15)**

| Metric | Arise | SEC-bench (n=200) | Delta |
|--------|-------|-------------------|-------|
| Builder | 93.3% (14/15) | 81.7% | +11.6 pp |
| Exploiter | 46.7% (7/15) | 32.2% | +14.5 pp |
| Fixer | 33.3% (5/15) | 22.3% | +11.0 pp |
| E2E | 33.3% (5/15) | 22.3% | +11.0 pp |
| Avg Cost | $9.05/instance* | $0.87/instance | 10x higher |

**Limitations**
- Cost needs further verification (Performed with local Claude Code CLI which is incompatible with Claude ADK framework)
- Exploiter/Fixer underperformed due to experiment setup flaw

### Experiment 2: Full Featured Tree ([Full Report](../projects/arise-sec-lion/experiments/exp2-full-featured-tree.md))

|---|---------|-------------|
