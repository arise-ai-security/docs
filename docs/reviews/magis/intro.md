# MAGIS Overview
MAGIS is an LLM-based multi-agent framework for GitHub Issue Resolution. It decomposes the complex task of resolving repository-level GitHub issues into a collaborative workflow among four specialized agents: **Manager**, **Repository Custodian**, **Developer**, and **QA Engineer**. Using GPT-4 as its base model, MAGIS achieves a 13.94% resolved ratio on SWE-bench — an eight-fold improvement over direct GPT-4 application. Based on the [research paper](https://arxiv.org/abs/2403.17927).
