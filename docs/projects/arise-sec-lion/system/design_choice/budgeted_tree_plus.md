# Design Choice 3: Recursive Planning and Working With Budget Allowance + Tree Growth Control + Better Inherited Prompting

## Budgeted Tree-Structured Agentic System 
This design choice builds upon the [Budgeted Tree-Structured Agentic System](./budgeted_tree.md) by incorporating additional probablitic agent transitions and context inheritances mechanisms to control tree growth and enhance inherited prompting.

**Note**: This system has no [budget update system](/docs/projects/arise-sec-lion/system/reinforcement_learning/budget_update.md) enabled yet. This tree only restricts the excessuve growth of the tree by checking the budget allowance before spawning new agents.

### Analysis
1. **Tree Growth Control**: Russian Roullette style mechanism to probabilistically force a supervisor agent to become worker agents. As can be observed, in the [previous desgin](./budgeted_tree.md#interactive-diagram), the tree can grow without bounds, leading to overthinking and lack of real focus. This approach employs the benefits of LLM model's intrisic capability to direct implement required work without excessive delegation. This helps to maintain a more manageable tree structure and ensures that the system remains efficient and focused on task completion.

2. **Enhanced Inherited Prompting**: Worker agents receive more context from their parent supervisor agents, including supervisors' own objectives, expectations, requirements, and justifications. This method also significantly increases the accuracy and relevance of the work performed by worker agents, as they have a clearer understanding of the overall task and its goals. The context passed down is accumulative, meaning that each worker agent inherits not only the immediate supervisor's context but also the summarized context from all ancestor supervisors up to the root. This creates a rich informational environment for each agent, enabling them to make more informed decisions and produce higher-quality outputs.

3. **High Performance**: Both previous two features contribute to the overall high performance of this agentic system. For the same task described above, the budgeted tree takes up to more than 200 agents but can not finish the work successfully. In contrast, this design choice completes the task with around 50 agents involved, demonstrating its efficiency and effectiveness in handling complex tasks.

4. **Unorganitzed Structure**: One drawback as shown in the Generated Files section is that the file structure generated by this agentic system is very unorganized. We should be able to mitigate the issue by introducing better prompt for every agent to follow a specific file structure convention.
