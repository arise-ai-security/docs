## Gold Patches
- We manually reviewed more than 20 instances of the [NIST dataset](https://nvd.nist.gov/) and confirmed there are no logical bugs.
- Throughout the SEC-bench pipeline, we could not find ground-truth patches. `seed.py` output does not include patches (only candidate commits), and the SEC-bench dataset output contains **AI-generated + human reviewed** patches.

**Note:** Although the `patches` column contains AI-generated code, most entries are based on real-world commits with commit hash and committer information.

#### Step explanation
1. `seed.py` parses raw OSV/CVE JSON files, extracts core metadata (`id`, `repo`, `fix commit`, `language`), and outputs `seed.jsonl`.
2. `report.py` visits reference URLs (GitHub, huntr.dev), scrapes bug descriptions and fix commit SHAs, and outputs `report.jsonl`.
3. `project.py` clones target repos and OSS-Fuzz, resolves base commit, fetches historical Docker context, and outputs `project.jsonl`.
4. Docker build process: `build_base_images.py` creates foundational images (`secb.base:YYYYMM`), then `build_instance_images.py` builds per-vulnerability images (`secb.x86_64.<instance_id>`).
